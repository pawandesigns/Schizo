SAHAY — GitHub Pages website package
Pawan Kumar Mishra

This is the complete static website. No build command, server, API key or ChatGPT account is needed to host this package.

Included
- index.html: the complete scrollable case study
- styles.css, fonts.css, script.js: appearance and interactions
- assets/: optimised project imagery and locally hosted fonts
- resources/: design registration, EMBRACE booklet and tracker instructions
- .nojekyll: publishes the static files directly on GitHub Pages

Publish
1. Extract this ZIP.
2. Add the contents to the root of your intended GitHub repository. index.html must be at the repository root, not inside another folder. Keep the assets and resources folders intact. GitHub Desktop is useful for uploading the complete folder; browser uploads can be done in batches.
3. Configure GitHub Pages to publish that repository folder using GitHub's instructions below.
4. Once GitHub provides the published Pages URL, use that URL for the Sahay project link on your Wix website.

Official setup instructions:
https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

Portability
All local assets use relative paths, so they work beneath a project URL such as /sahay/. The site does not depend on a ChatGPT-hosted domain. Portfolio and contact links point to Pawan's original destinations. Questionnaire, expert-review audio and full-resolution source links remain external, as in the original project.
